# Integrations

Tool and framework adapters for the PUDO AI DevOS.

## Purpose

Keep kernel and services tool-agnostic. Each integration translates PUDO config into platform-native format.

## Planned Adapters

| Integration | Path | Status |
| --- | --- | --- |
| Continue | `continue/` | v3.1 |
| Aider | `aider/` | v3.1 |
| Gemini CLI | `gemini-cli/` | v3.1 |
| LangGraph | `langgraph/` | v4 |
| OpenAI Agents SDK | `openai-agents/` | v4 |

## Adapter Rules

1. No business logic — translation only
2. Generated by `pudo init --tools=...` where possible
3. Reference kernel via `AGENTS.md`, not duplicated content
