# Stack Templates

These templates provide stack-specific PUDO rules that can be copied into a target repository or used by the `pudo init` CLI as stack guidance.

Each template keeps only stack-specific rules. Shared PUDO workflow, quality gates, token budget, and anti-hallucination rules live in the root docs.
