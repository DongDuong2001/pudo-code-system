# React + Vite PUDO Rules

Use PUDO: Plan -> Understand -> Develop -> Optimize.

## Stack Rules

- Identify routing, state management, and styling conventions before editing.
- Preserve component boundaries.
- Avoid global state when local state is sufficient.
- Cover loading, empty, disabled, error, and success states.
- Keep accessibility checks in scope for UI changes.
- Verify Vite env var naming before adding config.
