# Навык Программной Инженерии (Написание Кода)
> Skill, Coding, Implementation, Clean Code

## Контекст
Используйте этот промпт, когда у вас есть четкий план и вам нужно, чтобы ИИ сгенерировал фактический код реализации. Этот навык обеспечивает строгое соблюдение принципов чистого кода (Clean Code), тестируемости и надежной обработки ошибок.

## Переменные
- `{{specifications}}`: Подробные требования или шаги для нужного вам кода.
- `{{language_framework}}`: Используемый язык программирования и фреймворк.
- `{{existing_patterns}}`: Любые устоявшиеся паттерны в кодовой базе, которым должен следовать ИИ.

## Промпт
```text
Возьми на себя роль Senior Software Engineer. Мне нужно, чтобы ты написал готовый к продакшену код на основе следующих спецификаций:

Спецификации: 
{{specifications}}

Язык/Фреймворк: 
{{language_framework}}

Существующие паттерны в кодовой базе, которым нужно следовать:
{{existing_patterns}}

Пожалуйста, сгенерируй код реализации, придерживаясь следующих принципов:
1. **Чистый и Идиоматичный (Clean & Idiomatic):** Используй стандартные соглашения для языка. Держи функции небольшими и сфокусированными на одной ответственности (Принципы SOLID).
2. **Надежная обработка ошибок:** Не проглатывай (swallow) ошибки. Изящно обрабатывай крайние случаи (edge cases) и используй соответствующие границы ошибок (error boundaries) или исключения.
3. **Тестируемость (Testable):** Пиши код, который легко покрыть юнит-тестами. Используй внедрение зависимостей (dependency injection), где это уместно.
4. **Самодокументируемый (Self-Documenting):** Используй ясные, описательные имена переменных и функций. Добавляй комментарии только для объяснения того, *почему* делается что-то сложное, а не *что* именно делается.

Предоставь полные блоки кода, по возможности избегая сокращений.
```

## Пример использования

**Ввод:**
```text

Спецификации: 
Создай React хук `useDebounce`, который задерживает обновление значения до тех пор, пока не пройдет заданное время с момента последнего изменения.

Язык/Фреймворк: 
TypeScript, React 18

Существующие паттерны в кодовой базе, которым нужно следовать:
Всегда используй обобщенные типы (generic types) для кастомных хуков. Обеспечь строгую типизацию (strict typing).

Пожалуйста, сгенерируй код реализации, придерживаясь следующих принципов:
[...остальная часть промпта...]
```
