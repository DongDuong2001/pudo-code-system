# Навык Устранения неполадок и Отладки (Debugging)
> Skill, Debugging, SRE, Bug Fixing

## Контекст
Используйте этот промпт, когда сталкиваетесь с ошибкой (багом), трассировкой ошибки (error trace) или неожиданным поведением. Этот навык заставляет ИИ действовать как специалист по устранению неполадок (troubleshooter), систематически анализируя первопричины, а не просто угадывая решения.

## Переменные
- `{{error_message}}`: Точное сообщение об ошибке или вывод из логов.
- `{{behavior_description}}`: Что вы ожидали увидеть по сравнению с тем, что произошло на самом деле.
- `{{context_code}}`: Фрагмент кода, в котором происходит ошибка.

## Промпт
```text
Возьми на себя роль Senior Site Reliability Engineer (SRE) / Специалиста по устранению неполадок. Я столкнулся с багом, и мне нужна твоя помощь, чтобы систематически диагностировать и исправить его.

Сообщение об ошибке / Stack Trace:
{{error_message}}

Ожидаемое и Фактическое поведение:
{{behavior_description}}

Соответствующий контекст кода:
{{context_code}}

Пожалуйста, следуй этой методологии отладки:
1. **Анализ первопричины (Root Cause Analysis):** Проанализируй ошибку и код, чтобы на техническом уровне объяснить, *почему* именно происходит эта ошибка.
2. **Гипотезы (Hypotheses):** Приведи 1-2 вероятные причины, если первопричина не очевидна на 100% из предоставленного фрагмента.
3. **Исправление (The Fix):** Предоставь точные изменения кода, необходимые для решения проблемы.
4. **Предотвращение регрессий (Regression Prevention):** Кратко объясни, как это исправление гарантирует, что баг больше не повторится (например, обработка крайних случаев).

Не угадывай вслепую. Если тебе нужно больше информации для точной диагностики проблемы, попроси ее.
```

## Пример использования

**Ввод:**
```text
Возьми на себя роль Senior Site Reliability Engineer (SRE) / Специалиста по устранению неполадок. Я столкнулся с багом, и мне нужна твоя помощь, чтобы систематически диагностировать и исправить его.

Сообщение об ошибке / Stack Trace:
TypeError: Cannot read properties of undefined (reading 'map') at UserList.tsx:24

Ожидаемое и Фактическое поведение:
Я ожидал, что список пользователей отрендерится, но вместо этого приложение падает (crashes), когда API слишком долго не отвечает.

Соответствующий контекст кода:
const UserList = ({ users }) => {
  return <div>{users.map(u => <span key={u.id}>{u.name}</span>)}</div>
}

Пожалуйста, следуй этой методологии отладки:
[...остальная часть промпта...]
```
